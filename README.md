# Stack and Queue Implementations

## About Project
This repository contains basic implementations of **Stack and Queue** data structures using C++.

## Programs Included

1. Stack using Array
2. Stack using Linked List
3. Queue using Array
4. Queue using Linked List

## Operations
- **Stack:** Push, Pop, Peek and Display.
- **Queue:** Enqueue, Dequeue, Peek and Display.

## Technologies Used
- Programming Language: C++
- Data Structures: Stack and Queue
- Concepts: Arrays, Linked Lists and Pointers

## How to Run
Compile any program using:

```bash
g++ filename.cpp -o output
```

Run the generated executable:

```bash
output.exe
```

## Conclusion
This repository demonstrates the implementation of Stack and Queue using arrays and linked lists, helping to understand basic data structure operations in C++.
